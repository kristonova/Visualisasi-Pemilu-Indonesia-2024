pernah dipakai pada versi awal repository. Builder aktif tidak membacanya.

Audit lengkap menggunakan folder eksternal:

```text
D:\PROJECT\Scrapping Hasil Pemilu 2019 KPU\scrapping KPU
```

Jangan memakai jumlah file atau cakupan `src/` sebagai ukuran kelengkapan data
dashboard.
